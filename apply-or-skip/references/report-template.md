## 4. Core requirements

| Requirement | Evidence | Level | Source / date | Verdict |
|---|---|---|---|---|

Level is Owned / Co-led / Contributed / Exposure / Absent.

Discarded as Noise: list the lines you did not score, briefly.

## 5. Gap register

| Gap | Type | Cost to close | Proof artifact |
|---|---|---|---|

Type is Closeable / Narratable / Structural. Count structural gaps explicitly.

## 6. Presentation findings

- **Buried strengths** — evidence that clears a Core requirement but is not
  visible where a screener looks. Each one is a tailoring instruction.
- **Overreach** — claims in the current materials this JD would interrogate and
  the evidence would not survive.
- **Missing vocabulary** — required terms absent from the resume that the user's
  real experience honestly supports.

## 7. Tailoring brief

If the verdict is not Skip:

1. The three pieces of evidence to lead with, in order.
2. The rewrite: which section, what changes, why.
3. The one-line answer to the hardest screening question.
4. Placeholders the user must fill — every metric that is not already confirmed.
